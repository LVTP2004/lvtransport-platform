# ATLAS INCIDENT PROTOCOL V1

Status: ACTIVE
Created: 2026-06-04T12:36:04+02:00

## Purpose

Every significant failure becomes institutional memory.

## Incident Lifecycle

Detection
→ Classification
→ Containment
→ Investigation
→ Root Cause
→ Lesson
→ Protocol Update
→ Memory Sync

## Rules

1. No incident closes without root cause.
2. No incident closes without lesson.
3. Repeated incidents generate protocol.
4. Three similar incidents trigger Atlas review.
5. Contract incidents update Atlas Canonical Map.
