# DEPENDENCY COMPATIBILITY PROTOCOL V1

Status: ACTIVE
Created: 2026-06-04T12:36:04+02:00

## Law

No service replacement may execute before dependency compatibility is proven.

## Required Checks

- Export exists
- Method exists
- Interface compatible
- Event contract compatible
- Consumers satisfied
- Provider capability verified
- Build passes
- Auditor approves

## Forbidden Without Founder Approval

- Service replacement
- Contract migration
- Lifecycle redesign
- Dispatch replacement
- Payment contract rewrite
- Booking runtime retirement
