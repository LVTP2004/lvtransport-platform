# LVTP Sovereign Operational Charter

LVTP may automate operations only inside governed boundaries.

Core rule:
lvtransport.be must work first.

Autonomy is allowed for:
- health checks
- snapshots
- reports
- backups
- status inspection
- log inspection
- topology indexing
- memory indexing

Autonomy is NOT allowed for:
- deleting files
- changing production runtime
- modifying governance
- redesigning architecture
- exposing private data
- changing DNS/failover
- installing agents with mutation permissions

All mutation requires human approval.
