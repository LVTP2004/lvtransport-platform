# LVTransport — Codex Rules

Codex MUST:
- preserve founder-approved UX
- preserve operational philosophy
- preserve architecture boundaries
- preserve operational honesty

---

# Forbidden

Codex MUST NOT:
- redesign approved UX
- introduce fake operational data
- introduce fake realtime systems
- fabricate GPS or ETA
- invent analytics
- alter infrastructure scope outside task

---

# PR Requirements

Every PR must include:
- Motivation
- Description
- Testing
- Changed files
- Scope confirmation

---

# Mandatory Confirmations

Every PR must explicitly confirm:
- no fake operational behavior
- no forbidden infrastructure changes
- no unrelated redesigns
- no fake data introduced

---

# Operational Philosophy

LVTransport is:
- operational infrastructure
- AI-assisted operations
- realtime orchestration
- transport operations OS

NOT:
- generic SaaS
- fake dashboard platform
- demo application
