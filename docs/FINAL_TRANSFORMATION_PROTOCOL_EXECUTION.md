## Operational Discipline Rules

- Every subsystem event must map to a canonical lifecycle state transition.
- Every recovery pathway must preserve customer-visible continuity.
- Every Moni message must remain calm, truthful, and operationally grounded.
- Every major release must produce updated scorecard JSON + Markdown artifacts.

## Definition of “Transformation Complete”

LVTP is transformation-complete when:

1. Transformation Readiness stays above **90%** across consecutive validations.
2. No critical regressions in lifecycle, messaging, payment, or airport coordination paths.
3. Founder pilot operations run without unresolved severity-1 incidents.
4. Customer experience remains calm, premium, and predictable during disruptions.
