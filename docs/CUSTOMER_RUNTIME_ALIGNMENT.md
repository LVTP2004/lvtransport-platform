# Customer Runtime Narrative Alignment

## Purpose
Align customer-facing language to LVTransport as **operational mobility infrastructure** with calm, trust-first, premium communication.

## Required Narrative Vocabulary
- operational mobility infrastructure
- continuity-aware transport
- deterministic premium mobility
- operational reliability
- governed mobility coordination

## Copy Rules
1. Use concise, confidence-oriented microcopy.
2. Avoid dashboard, growth-hack, or hype wording.
3. Avoid AI buzzword density; AI may be referenced only as support for operational reliability.
4. Every customer-visible status should map to an operational lifecycle state.

## UI Tone Contract
- Premium graphite/gold visual hierarchy remains unchanged.
- Messaging emphasizes certainty, timestamps, and verified status.
- Escalation language remains calm and accountable.

## Acceptance Criteria
- No customer screen uses “control tower”, “telemetry wall”, “autonomous”, or speculative ETA phrasing.
- Booking, pricing, and ride-state copy explicitly references verification and continuity when applicable.
