# ATLAS MEMORY ARCHITECTURE V1

Status: ACTIVE
Created: 2026-06-04T12:59:48+02:00

## Purpose

Organize Atlas institutional memory into stable domains.

## Memory Domains

LAW MEMORY:
Permanent governance principles.

PROTOCOL MEMORY:
How the system must act.

CASE MEMORY:
What happened.

LESSON MEMORY:
What was learned.

ARCHAEOLOGY MEMORY:
Backups, rollbacks, repair artifacts and historical traces.

DECISION MEMORY:
Founder-approved decisions.

## Core Chain

Incident
→ Case
→ Lesson
→ Protocol
→ Law
→ Decision
→ Memory

## Current Operating Law

No expansion before convergence.
No repair before canonical truth.
No promotion to VPS before Atlas approval.
Unknown problems enter Delta Queue before protocol creation.
Backups require Atlas classification.
Founder decisions must be recorded.
