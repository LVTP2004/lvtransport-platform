# DELTA QUEUE PROTOCOL V1

Status: ACTIVE
Created: 2026-06-04T12:51:49+02:00

## Purpose

Prevent uncontrolled protocol growth.

All unknown problems enter Delta Queue before new protocols are created.

## Flow

Unknown problem
→ Delta Queue
→ Existing protocol check
→ Existing case check
→ Existing lesson check
→ Delta Team review
→ Founder decision
→ Case/protocol only if needed

## Rules

1. Do not create a new protocol if an existing protocol applies.
2. Do not create a new case if an existing case matches.
3. Do not execute from queue.
4. Queue only prepares review.
5. Founder OS decides escalation.
6. Closed queue items must produce memory.

## Folders

open:
New unresolved items.

review:
Items under Delta Team review.

closed:
Resolved with decision or protocol.

rejected:
Not Delta-worthy, duplicate, or insufficient evidence.
