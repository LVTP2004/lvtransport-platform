# Smart Pricing Engine Architecture (Preparation)

This document describes architecture-only scaffolding for smart pricing in LV Transport Platform.

## Included capabilities

- Dynamic fare calculation module structure
- Day/night pricing preparation
- Minimum fare architecture
- Airport surcharge and fixed-rate preparation
- Waiting time pricing preparation
- Long distance pricing preparation
- Business/VIP pricing preparation
- Admin-managed custom fare rule structure
- Route estimate and booking quote architecture
- Realtime ETA adjustment preparation
- Surge pricing preparation
- Customer fare preview and quote state preparation
- Tax/VAT and invoice model preparation
- Driver payout and commission preparation
- Discounts, promo codes, and monthly business plan preparation
- Subscription pricing preparation

## Not implemented

- Real payment processing
- Stripe integration
- Real distance API calls
- Production billing logic
- Accounting integration
