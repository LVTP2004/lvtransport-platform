# MoniRide Operational Cognition

## Objective
Deliver bounded cognition that explains operations without mutating runtime state.

## Allowed AI Behaviors
- Explain continuity and replay outcomes.
- Summarize operational transitions.
- Correlate evidence for investigations.
- Propose bounded next-step guidance.

## Forbidden AI Behaviors
- Runtime mutation
- Autonomous replay execution
- Invented operational state
- Autonomous orchestration

## Output Contract
- Deterministic cognition rendering
- Evidence links
- Lineage links
- insufficientEvidence flag when applicable
